# Premium Member C 端 · Design System

版本：1.0（2026-11-27）
范围：`c-app` 六页（首页 / 登录 / 我的 / AI 创作 / 权益 / 工单），H5 与 Capacitor Android 共用一套 token。
基线：`35be2e5`。接口、字段、业务文案含义不变，仅重做视觉与页面结构。

## 1. Product Truth

- 用户：已购买或准备购买会员权益的 C 端用户，主要在 Android 手机夜间/室内使用。
- 任务：看模板 → 上传素材 → 生成作品；查额度 → 领权益；看会员资产 → 提工单。
- 语气：安静、直接、媒体优先。主色只负责「可操作」，不负责装饰整页。
- 成功标准：一屏能看懂「现在有什么、下一步点哪里」，不靠解释文字。

## 2. Tokens

### 2.1 色彩

| Token | 值 | 角色 |
|---|---|---|
| `--bg` | `#0B0B0D` | 页面底色（近黑，带极轻冷调，不用纯黑） |
| `--surface` | `#141416` | 卡片、输入框、列表容器 |
| `--overlay` | `#1C1C1F` | TabBar、浮层、选中底 |
| `--line` | `rgba(255,255,255,0.08)` | 分隔线 |
| `--border` | `rgba(255,255,255,0.06)` | 卡片描边 |
| `--text` | `#F5F5F7` | 主文字、标题 |
| `--text-muted` | `#9A9AA2` | 副标题、说明、未选中 Tab |
| `--text-disabled` | `#5A5A60` | 禁用、占位 |
| `--accent` | `#3DDC97` | 主操作、选中态、额度数字 |
| `--accent-gradient` | `linear-gradient(135deg,#2BD6B0,#3DDC97)` | 主按钮、中心创作键 |
| `--danger` | `#FF6B6B` | 错误、退出、失败状态 |
| `--warning` | `#F5C451` | 处理中、待发放 |

光晕只允许出现在两处：首页 hero 与 TabBar 中心创作键。使用低透明度青绿径向渐变，不铺满整屏。
封面渐变按模板分组使用低饱和暗色：

- 照片：`#123B3A → #0E1E2A`，标签青绿
- 换装：`#2A1733 → #16111F`，标签粉紫
- 视频：`#332414 → #181310`，标签暖金

### 2.2 字阶与字重

字体：`-apple-system, "PingFang SC", "HarmonyOS Sans SC", "MiSans", "Noto Sans SC", "Source Han Sans SC", sans-serif`

| Token | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| `--font-page` | 28 / 1.25 | 700 | 页面主标题 |
| `--font-hero` | 24 / 1.3 | 600 | hero 标题 |
| `--font-section` | 18 / 1.4 | 600 | 区块标题 |
| `--font-card` | 16 / 1.4 | 600 | 卡片标题 |
| `--font-body` | 14 / 1.6 | 400 | 正文 |
| `--font-sub` | 12 / 1.5 | 400 | 副标题、说明、时间 |
| `--font-number` | 30 / 1.1 | 700 | 余额、额度等关键数字（tabular-nums） |

`ui-ux-pro-max` 推荐的 Inter + 紫色系不采用：中文大标题在 Android 上回退不可控，紫色也与业主指定的品牌绿冲突。
移动端正文最小 14（业主简报），关键说明保持 12 但只用于非关键信息；颜色对比按 WCAG AA 校验。

### 2.3 间距

4px 基准：`4 / 8 / 12 / 16 / 24 / 32 / 48`。

- 页面左右：16
- 卡片内：16
- 区块之间：24
- 卡片内元素：8 / 12
- TabBar 内容下留白：`56 + env(safe-area-inset-bottom)`

### 2.4 圆角

| Token | 值 | 用途 |
|---|---|---|
| `--radius-card` | 16 | 卡片、封面、弹层 |
| `--radius-control` | 12 | 按钮、输入框 |
| `--radius-pill` | 999 | 胶囊、徽标、头像 |

### 2.5 阴影与层级

- 默认层级靠 `surface` 色差 + 1px `border`，不给每张卡加阴影。
- `--shadow-float`：`0 12px 32px rgba(0,0,0,0.45)`，只用于 TabBar。
- `--shadow-accent`：`0 8px 28px rgba(61,220,151,0.28)`，只用于中心创作键。
- z-index：内容 0 / TabBar 30 / 浮层 50。

### 2.6 动效

- 时长：按压 120ms，状态切换 180ms，页面入场 240ms。
- 曲线：`cubic-bezier(0.2, 0.8, 0.2, 1)`，只动 `opacity / transform / background-color / border-color`。
- 骨架屏允许 1.6s 透明度呼吸；`prefers-reduced-motion: reduce` 下全部关闭。

## 3. Components

### 3.1 TabBar

- 固定底部，4 项：首页 / 创作（中心凸起）/ 权益 / 我的。
- 高度 56 + 底部安全区，背景 `rgba(20,20,22,0.94)` + 1px 顶部分隔线。
- 图标 24×24 线性 SVG，stroke 1.5，`currentColor`；文字 12。
- 未选中 `--text-muted`，选中 `--accent`；点击目标最小 48×48。
- 中心创作键 56×56 圆形，渐变实心 + 光晕，向上凸出 18，图标为加号；按下 `opacity:.85`。

### 3.2 卡片

- 统一 `surface + 1px border + 16 圆角 + 16 内边距`。
- 媒体卡必须「封面 + 标题 + 副标题」三段；封面比例 3:4，无图时用分组渐变 + 2–4 字大字标签。
- 列表卡不嵌套卡片；卡内分组用 1px 分隔线，不用第二层边框。

### 3.3 按钮

| 层级 | 样式 | 高度 |
|---|---|---|
| Primary | `--accent-gradient`、深色文字 `#04140D`、12 圆角 | 48 |
| Secondary | 透明底、`--border` 描边、`--text` | 48 |
| Ghost | 无底无框、`--text-muted` | 44 |

禁用：`--overlay` 底 + `--text-disabled`；加载中保留宽度并禁用重复点击；按下透明度 0.85。

### 3.4 输入框

- 高度 48，`--surface` 底，1px `--border`，12 圆角，内边距 0 14。
- placeholder 用 `--text-disabled`；聚焦边框 `--accent`，不加外发光。
- 标签在输入框上方独立一行，12 / `--text-muted`；错误文案紧贴输入框下方，`--danger`，12。

### 3.5 徽标 / 胶囊

- 999 圆角，高度 24–28，字号 12。
- 状态：正常/已领取用 `rgba(61,220,151,.14)` + `--accent`；处理中用 `rgba(245,196,81,.14)` + `--warning`；失败/停用用 `rgba(255,107,107,.14)` + `--danger`。

### 3.6 骨架屏

- 灰块 `#1C1C1F`，圆角 12/16，禁止白底空图。
- 首页模板区、创作模板网格、权益列表、我的会员卡在加载时显示同尺寸骨架，避免内容跳动。

### 3.7 空态

- 深色容器 + 一行说明 + 一个主操作，不用插画占位。
- 文案沿用现有业务文案，不新增营销语。

## 4. 页面结构

### 首页

```
[安全区]
标题：AI 创作
[会员状态条] 创作会员 · 图片剩余 x · 视频剩余 y（游客：登录后查看）
[促销/会员卡位] 读 content BANNER，暗色渐变 + 标题
[三个功能瓦片] AI 写真 | 一键换装 | 图生视频（点击带类型进创作页）
区块标题：精选模板
[2 行 × 4 列] 渐变封面 + 左下角模板名
[会员权益行] 皇冠 + 会员权益 + 本期可选 N 项 + 箭头
[TabBar]
```

### 创作

```
[安全区]
返回 + 标题（AI 写真 / 一键换装 / 图生视频）
[上传区] 220 方形预览框 + 上传照片（上传后可重选）
区块标题：选择模板
[横向滚动] 渐变封面 + 名称（选中描边 + 右上勾选）
[参数行] 视频：时长 / 720P；写真：风格 / 比例
[消耗条] 本次消耗 1 次图片/视频额度 · 剩余 N 次
[开始生成] 品牌绿渐变；游客文案为登录后生成
[我的作品 ›] 展开后显示作品缩略图 / 名称 / 删除
[TabBar]
```

### 权益

```
[安全区]
标题：权益中心 / 周期说明
[剩余名额胶囊]
[权益卡列表] 渐变封面 + 名称 + 描述 + 状态徽标 + 领取按钮
[领取成功浮层] 卡密 + 保存确认
[领取历史] 名称 + 卡密 + 日期 + 状态
[TabBar]
```

### 我的

```
[安全区]
[头像 + 昵称 + 手机号]
[会员卡] 等级 / 到期 / 余额 / 积分 / 状态
[功能列表] 权益中心 / AI 创作 / 我的工单
[设置列表] 客服 / 协议 / 退出登录
[TabBar]
```

### 登录

```
[安全区]
品牌标识 + 标题：登录会员账号
副标题：使用手机号和密码查看会员权益
[手机号输入]
[密码输入]
[登录主按钮]
[错误文案]
```

工单页沿用同一套 token：标题 + 新建主按钮 + 工单列表卡（标题 / 分类 / 时间 / 状态）+ 详情时间线。

## 5. Android 适配

- 状态栏：`navigationStyle: custom`，页面顶部使用 `calc(env(safe-area-inset-top) + 12px)`；H5 中 env 为 0。
- 沉浸式：`navigationBarTextStyle: white`、`backgroundColor: #0B0B0D`；H5 设置 `theme-color #0B0B0D`。
- 刘海/手势区：所有固定元素使用 `env(safe-area-inset-bottom)`；页面底部预留 `TabBar 高度 + 安全区`。
- 触控：Tab 项、按钮、输入框均 ≥48dp；相邻可点区域间距 ≥8。
- 返回：工单/详情页用 `uni.navigateBack`；无页面栈时回退「我的」；Android 物理返回键沿用 uni-app 页面栈默认行为。
- 字体：优先 Android 系统中文字体（HarmonyOS Sans SC / MiSans / Noto Sans SC），不加载远程字体，避免首屏闪烁。
- 深色图标：状态栏与导航栏均为浅色图标；不在浅色底上使用深色文字。
- 打包配置与 `build:h5` 不变；H5 只做同一套 token 的降级渲染（隐藏凸起键的阴影、无安全区时按 0 处理）。

## 6. 参考取舍（即梦 / 可灵）

取：

- 近黑底 + 大标题 + 图片/渐变优先的版面。
- 底部四项 + 中心凸起创作键。
- 3:4 封面卡片、两列瀑布流、低透明度青绿光晕。
- 权益页「额度胶囊 + 权益卡 + 领取记录」的信息顺序。
- 我的页「头像/昵称 → 会员卡 → 分组设置列表」。

不取：

- 社区、关注、点赞、评论、作品广场等社交能力。
- 视频流自动播放、创作圈、邀请有礼等本期不存在的业务。
- 参考中的纯黑 `#000` 大底、亮青大面积铺色、浅色会员页。
- 任何假数据、假评分、假用户数。

## 7. Do / Don't

Do：

- 每屏只保留一个视觉焦点：首页 hero、创作选中模板、权益额度、我的会员卡。
- 卡片三段式；无图时用渐变封面 + 标签。
- 状态同时用颜色和文字表达，不只靠颜色。
- 加载用骨架，错误给可重试操作。

Don't：

- 不用紫渐变当默认科技感，不用渐变文字、霓虹边框、玻璃高光。
- 不用 emoji 当图标，不手绘 SVG 人物。
- 不在卡片里再套卡片，不用左侧彩色 border 装饰。
- 不写 hover-only 交互，不写滚动监听动效。

## 8. Agent 提示

- 改页面前先读本文件；所有颜色、圆角、间距只引用 token，不写裸值。
- 文案、接口、字段保持现状；新增的只有结构与必要的分组标签。
- 交付前用 390×844 实际渲染截图核对：深色底、封面/渐变、TabBar 可见、无白底纯文字卡。
