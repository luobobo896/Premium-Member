订阅制上线后 AI 统一切换为积分：提交按类型扣 `POINTS_PHOTO_PRICE/POINTS_DRESSUP_PRICE/POINTS_VIDEO_PRICE`，失败写 `REFUND`。

## 数据模型

DDL 在 `admin-server/admin-bootstrap/src/main/resources/db/schema.sql`，种子在 `data.sql`，均可重复执行。

| 表 | 关键字段 | 约束 |
|---|---|---|
| `ai_template` | `code`、`name`、`type`、`category`、`cover_url`、`params`、`status`、`version_no`、`sort` | `code` 唯一；`type` 仅 `PHOTO/DRESSUP/VIDEO`；`params` 为 JSONB |
| `ai_task` | `task_no`、`member_id`、`period_id`、`template_id`、`type`、`status`、`input_asset_id`、`output_asset_id`、`supplier_task_no`、`fail_reason`、`cost_cents`、`idempotency_key`、`mock_result`、`created_at`、`finished_at` | `task_no` 唯一；`idempotency_key` 唯一；状态受 CHECK 约束；`mock_result` 仅 dev/test 使用 |
| `quota_ledger` | `period_id`、`kind`、`delta`、`balance_after`、`reason`、`ref_task_id`、`idempotency_key`、`operator`、`created_at` | 只追加；`idempotency_key` 唯一；`reason` 仅 `RESERVE/SETTLE/RELEASE/REFUND/ADJUST` |
| `asset` | `owner_member_id`、`purpose`、`mime`、`size`、`storage_key`、`status`、`expire_at`、`expose_count` | `storage_key` 唯一；`purpose` 仅 `INPUT/OUTPUT`；`status` 仅 `ACTIVE/DELETED/EXPIRED` |
| `asset_expose` | `token`、`asset_id`、`expire_at`、`remaining_downloads`、`created_at` | `token` 为 32 字节随机 URL-safe 值；只服务本地无 OSS 时的临时输入 |

模板首期 20 个：照片 8、换装 8、视频 4。`data.sql` 用 `ON CONFLICT (code) DO NOTHING`，重复执行不会覆盖后台已编辑的模板。

## 状态机

```text
提交 -> QUEUED -> RUNNING -> SUCCESS
                         -> FAILED
                         -> REJECTED
                         -> UNKNOWN
```

- `SUCCESS`：写入产出 `asset`，账本追加 `SETTLE`。
- `FAILED` / `REJECTED`：明确失败或拒绝，账本追加 `RELEASE`，返还 1 次。
- `UNKNOWN`：供应商结果未知，任务只允许查询，不自动重试、不释放额度。
- 状态更新都带 `WHERE status = 'RUNNING'` 条件，重复回调不会再次结算。
- 进程在 `RUNNING` 时崩溃会留下悬挂任务；本轮没有补偿/对账任务，见“未验证项”。

## 账本规则

周期额度来自周期订单绑定的 `plan_version`：`ai_image_quota` 默认 20，`ai_video_quota` 默认 3。

| 动作 | delta | 余额 | 幂等键 |
|---|---|---|---|
| `RESERVE` | -1 | `limit + sum(delta) - 1` | `RESERVE:{taskNo}` |
| `SETTLE` | 0 | 保持预占后的余额 | `SETTLE:{taskNo}` |
| `RELEASE` | +1 | 返还 1 次，不超过上限 | `RELEASE:{taskNo}` |
| `REFUND` / `ADJUST` | 预留 | 预留给人工补偿 | 按业务唯一键 |

- 提交时对 `pm_member_period` 行加 `FOR UPDATE`，同一周期的预占串行执行，避免并发超卖。
- 图片额度由 `PHOTO + DRESSUP` 共用；`VIDEO` 独立计次。
- 剩余额度 = `limit + sum(delta)`，并限制在 `0..limit`；`balance_after` 同步落库，便于审计。
- `quota_ledger` 只追加；结算/释放依赖唯一键，重复执行 `ON CONFLICT DO NOTHING`。

## 幂等与跨期

- `POST /c/ai/tasks` 以 `idempotency_key` 判定同一请求；重复键返回同一 `taskNo`，不会重复预占或创建任务。
- 任务先插入，再预占额度，二者在同一事务；额度不足或插入失败会整体回滚。
- 任务提交时把当前生效周期写入 `ai_task.period_id`。异步完成时只读该字段，不重新取“当前周期”，因此跨期完成仍结算原周期。

## 接口

### C 端

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/c/ai/templates?type=&category=` | 上架模板，按类型/分类筛选 |
| POST | `/c/ai/assets` | multipart 上传，字段名 `file`，最大 20MB |
| POST | `/c/ai/tasks` | `{"templateId":1,"inputAssetId":1,"idempotencyKey":"..."}` |
| GET | `/c/ai/tasks/{taskNo}` | 只能查询自己的任务 |
| GET | `/c/ai/tasks?status=` | 当前会员最近 100 条任务 |
| DELETE | `/c/ai/works/{id}` | 删除成功作品的产出文件；任务和账本保留 |
| GET | `/c/quota` | 当前周期图片/视频额度 |
| GET | `/c/assets/{token}` | 仅本地无 OSS 时的临时输入，随机 token、10 分钟、限次 |

OSS 模式下，接口返回对象 key 的 30 分钟签名 URL；本地模式仍通过 `/c/ai/files/{storageKey}` 读取。
storage key 为随机 UUID，删除或过期的资产返回 404。
`mockResult` 是 dev/test 专用的模拟开关：`FAIL`、`REJECT`、`UNKNOWN`；生产 profile 忽略该字段。

## Provider 与存储

`AiProvider` 在 `c-biz/ai/provider`：

- `MockAiProvider`：`AI_PROVIDER=mock`（默认）时生效，异步延时 1.2 秒，照片/换装生成 900x1200 PNG 占位图，视频返回 1 秒 MP4 占位文件。
- `DashScopeAiProvider`：`AI_PROVIDER=dashscope` 时启用，接入阿里云百炼：
  - 文生图 `wanx2.1-t2i-turbo`，`POST /api/v1/services/aigc/text2image/image-synthesis`。
  - 图片编辑/换装 `wanx2.1-imageedit`，`POST /api/v1/services/aigc/image2image/image-synthesis`，`function=description_edit`。
  - 图生视频默认 `wan2.5-i2v-preview`（实测约 1 分钟），`POST /api/v1/services/aigc/video-generation/video-synthesis`，480P / 5 秒；`wanx2.1-i2v-turbo` 仅作备选，排队可能极长。
  - 统一异步轮询 `GET /api/v1/tasks/{task_id}`，间隔 3 秒；图片超时 2 分钟，视频超时 10 分钟，超时置 `UNKNOWN` 并保留 `task_id`/`request_id`。
  - 设置 `AI_PROVIDER=dashscope` 但没有 `DASHSCOPE_API_KEY` 时自动回退 `MockAiProvider`，本地仍可跑通。
- `UnsupportedAiProvider`：未匹配到任何实现时由 `AiProviderConfig` 兜底，显式失败，不会静默成功。

错误映射：

| 供应商情况 | 任务状态 / 错误码 |
|---|---|
| 401 / 403、无 key | `FAILED` / `AI_PROVIDER_NOT_READY` |
| 模型未开通 | `FAILED` / `AI_PROVIDER_NOT_ENABLED`，原因带模型名 |
| 限流、欠费、额度不足 | `FAILED` / `AI_PROVIDER_RATE_LIMITED` |
| 内容审核拒绝 | `REJECTED` / `AI_CONTENT_REJECTED` |
| 输入图下载 403 / 不可访问 | `FAILED` / `AI_PROVIDER_INPUT_UNREACHABLE` |
| 参数非法 | `FAILED` / `AI_PROVIDER_BAD_REQUEST` |
| 轮询超时 | `UNKNOWN` / `AI_PROVIDER_TIMEOUT`，保留 `task_id`/`request_id` |

`task_id` 写入 `ai_task.supplier_task_no`；失败时 `request_id` 与 `task_id` 一并写入 `fail_reason`，便于供应商侧排查。

`StorageService` 在 `c-biz/ai/storage`：

- `OssStorageService`：配置 `OSS_ENDPOINT`、`OSS_BUCKET`、`OSS_ACCESS_KEY_ID`、`OSS_ACCESS_KEY_SECRET` 后启用，对象 key 形如 `premium-member/ai/{env}/{input|output}/{yyyyMMdd}/{uuid}.{ext}`。
- `LocalStorageService`：OSS 未配置时自动回退，目录由 `AI_STORAGE_DIR` 控制，默认 `./data/ai`。
- 输入图：上传即写 OSS；换装/图生视频时生成 10 分钟签名 URL 给 DashScope；任务终态后删除输入对象并标记 asset 为 `DELETED`。
- 产物：DashScope 结果 URL 立即下载并写 OSS；C 端返回 30 分钟签名 URL，数据库只存 objectKey，不存永久直链。
- 无 OSS 的本地开发：使用 `/c/assets/{token}` 临时暴露输入，token 随机 32 字节、默认 10 分钟、限次下载，`asset.expose_count` 记录下载次数；生产以 OSS 为准。

### OSS / DashScope 配置

| 环境变量 | 说明 |
|---|---|
| `AI_PROVIDER` | `mock` 或 `dashscope` |
| `DASHSCOPE_API_KEY` | 只从环境变量读取，禁止入库、日志、错误串 |
| `DASHSCOPE_BASE_URL` | 默认 `https://dashscope.aliyuncs.com` |
| `DASHSCOPE_IMAGE_MODEL` / `DASHSCOPE_EDIT_MODEL` / `DASHSCOPE_VIDEO_MODEL` | 三个模型名 |
| `DASHSCOPE_POLL_INTERVAL` | 默认 `3s` |
| `DASHSCOPE_IMAGE_TIMEOUT` / `DASHSCOPE_VIDEO_TIMEOUT` | 默认 `2m` / `10m` |
| `OSS_ENDPOINT` | 例 `https://oss-cn-shenzhen.aliyuncs.com` |
| `OSS_BUCKET` | 例 `demopt` |
| `OSS_PREFIX` | 例 `premium-member/ai/prod` |
| `AI_SIGNED_URL_TTL_SECONDS` | 产物签名 URL 有效期，默认 `1800` |
| `PUBLIC_ASSET_BASE_URL` | 仅本地无 OSS 时使用，填服务公网/局域网地址 |

生产只需要把 OSS 四项凭证写进 `deploy/.env`，Docker/nginx 不需要额外反代 OSS。
当前允许 bucket `public-read` 先用主账号 AK 跑通；后续 TODO：改 private ACL，创建只具备该 bucket
`PutObject/GetObject/DeleteObject` 的 RAM 子账号，并给输入前缀配置 7 天生命周期。

## 未验证项与风险

- 未做 `RUNNING` 悬挂任务的对账与重试；进程崩溃后只能人工改状态或补账。

- `c-app` 只验证了 `build:h5` 和 H5 浏览器页面，未在 iOS/Android 真机验证原生文件选择。
- OSS 当前允许 bucket `public-read` + 主账号 AK；后续应改 private ACL、RAM 子账号最小权限，并给输入前缀配 7 天生命周期。
