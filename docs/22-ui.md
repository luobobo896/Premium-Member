# C 端 UI 重做（item 30）

基线：`35be2e5`。范围：仅 `c-app` 六页；`c-h5`、接口、后端字段和业务文案含义未改。
视觉规范源文件：`../c-app/DESIGN.md`（tokens、组件、页面结构、Android 适配、参考取舍）。

## 设计方向

参考 即梦 / 可灵 的媒体优先暗色界面，但不复制其社交、视频流与活动能力：

- 近黑底 `#0B0B0D` + 深色卡片，主色青绿 `#3DDC97` 只用于操作与额度。
- 大标题、封面优先、少量低透明度光晕；卡片统一「封面 + 标题 + 副标题」。
- 无素材时用程序化渐变封面 + 大标签，按照片 / 换装 / 视频分组配色。
- `ui-ux-pro-max` 推荐的紫色系与 Inter 不采用：与业主指定品牌绿冲突，且中文标题使用系统字体更稳定。

## 布局结构

### 首页（AI 创作）

1. 顶部标题「AI 创作」。
2. 会员状态横条：创作会员 · 图片剩余 x · 视频剩余 y；游客显示「登录后查看」，点击去登录。
3. 促销/会员卡位：读 `BANNER` content 配置，暗色渐变；无配置时用默认文案。
4. 三个功能瓦片：AI 写真 / 一键换装 / 图生视频，点击写入 `pm_ai_type` 后进入创作页。
5. 「精选模板」2 行 × 4 列，封面上叠左下角模板名。
6. 会员权益行：皇冠 + 会员权益 + 本期可选 N 项 + 箭头。
7. 底部 TabBar：首页 / 创作（中间凸起）/ 权益 / 我的。

### 创作详情

1. 返回 + 标题（AI 写真 / 一键换装 / 图生视频）。
2. 220×220 上传框；上传后显示缩略图与「重新选择」。
3. 「选择模板」横向滚动，选中态描边 + 右上角勾选。
4. 参数行：视频显示时长 / 720P；写真与换装显示风格 / 比例（取自模板 params）。
5. 消耗提示条：本次消耗 1 次图片/视频额度 · 剩余 N 次。
6. 主 CTA「开始生成」，游客为「登录后生成」；下方「我的作品 ›」展开作品列表。
7. 底部 TabBar。

### 权益 / 我的 / 登录 / 工单

- 权益：周期说明 → 剩余名额胶囊与进度 → 权益卡列表（渐变封面 + 状态徽标 + 领取按钮）→ 领取历史；成功后浮层仅展示一次卡密。
- 我的：头像/昵称/手机号 → 会员卡（等级、到期、余额、积分、状态）→ 权益/AI/工单入口 → 退出。
- 登录：品牌字、标题、手机号/密码输入、渐变主按钮；错误文案紧贴表单。
- 工单：返回 + 标题、新建工单、工单列表、详情时间线与客服回复；沿用原有接口和文案。

## 组件约定

- 卡片、按钮、输入框、胶囊、骨架、空态、错误提示统一在 `App.vue` 全局类中定义；页面只做布局。
- TabBar、图标、渐变封面分别是 `AppTabbar.vue`、`AppIcon.vue`、`GradientCover.vue`。
- 图标为内联 SVG 线性图标，24×24，stroke 1.5，不使用 emoji。
- 骨架屏替代白底空态；错误态给「重新加载」，空态保留业务文案。
